TANNETVISION 已升级为 Pages CMS 免费后台版。

以后不需要再修改 data.js，也不需要手写 assets 数组。

请优先查看：
README-PagesCMS免费后台.md

最简单的使用方式：
1. 把整个网站上传到 GitHub。
2. 打开 Pages CMS，并用 GitHub 登录。
3. 选择该仓库。
4. 直接在后台编辑：网站设置 / 项目 / 经历 / 视频 / 照片 / LUT / 联系方式。
5. 保存后，内容会写回 GitHub；连接 Cloudflare Pages 后会自动重新部署。

网站内的 /admin/ 是后台入口提示页，会带你打开 Pages CMS。
